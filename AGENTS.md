# AGENTS.md

Laravel 13 + Svelte 5 chat app with Inertia.js v3, Tailwind CSS 4, shadcn-svelte, and Laravel Reverb.

## Stack

| Layer | Tech |
|-------|------|
| Backend | PHP 8.3+, Laravel 13, Inertia-Laravel |
| Frontend | Svelte 5, Inertia-Svelte, TypeScript |
| CSS | Tailwind CSS 4, shadcn-svelte (Bits UI), `tw-animate-css` |
| Real-time | Laravel Reverb (server) + Pusher JS (client) |
| Testing | Pest PHP 4 (backend), none for frontend |
| SSR | Inertia SSR (enabled, runs on `http://127.0.0.1:13714`) |

## Commands

```sh
# ---------- Dev ----------
composer dev              # Run everything: server + queue + logs + Vite (concurrently)
npm run dev               # Vite dev server only
php artisan reverb:start  # WebSocket server

# ---------- Build ----------
npm run build             # Client build
npm run build:ssr         # Client + SSR build

# ---------- Lint / Format / Typecheck ----------
composer lint             # PHP Pint (Laravel preset)
composer lint:check       # Pint dry-run
composer types:check      # PHPStan (level 7, app/ + routes/ + config/ + database/)
npm run lint              # ESLint (auto-fix)
npm run lint:check        # ESLint dry-run
npm run format            # Prettier (resources/)
npm run format:check      # Prettier dry-run
npm run types:check       # svelte-check

# ---------- Test ----------
php artisan test          # Run Pest PHP tests (SQLite in-memory)
composer test             # lint:check + types:check + test

# ---------- CI ----------
composer ci:check         # npm lint:check + format:check + types:check + test
```

## Key details

- **Generated code**: `resources/js/{actions,routes,wayfinder}/` are generated by `laravel/wayfinder` + `@laravel/vite-plugin-wayfinder` and gitignored. Dont edit them.
- **SSR**: `bootstrap/ssr/` is gitignored, built via `npm run build:ssr`.
- **`.npmrc` sets `ignore-scripts=true`**. If you need postinstall scripts, add `--ignore-scripts=false`.
- **pnpm-workspace.yaml** is present but the project uses `npm` (lockfile is `package-lock.json`, not `pnpm-lock.yaml`). pnpm only hoists `@inertiajs/core`.
- **Custom XSRF cookie/header**: `MY-XSRF-TOKEN` / `X-MY-XSRF-TOKEN` (configured in `resources/js/app.ts`).
- **Svelte 5 runes** (`$state`, `$derived`, `$effect`, `$props`). No legacy patterns.
- **`@/` alias** -> `resources/js/`. Alias configured in `tsconfig.json` paths.
- **shadcn-svelte** components live in `resources/js/components/ui/`, use `sera` style, icons from `lucide-svelte`.
- **Route helpers** in `resources/js/routes/` (generated) are TypeScript-safe route definitions. Use `route('name')`.
- **Tailwind CSS 4** uses `@import`, NOT `@config`. No `tailwind.config.js` / `postcss.config.js`.
- **Broadcasting**: `ChatSent` event broadcasts on `global-chat` channel as `chat.sent`.

## Architecture

```
app/
  Events/ChatSent.php      # Broadcasts on 'global-chat' channel
  Http/Controllers/
    AuthController.php      # Login/register via Inertia
    ChatController.php      # Chat index (GET) + store (POST)
  Models/Chat.php            # Belongs to User
  Models/User.php            # Has many Chats

resources/js/
  app.ts                    # Inertia app bootstrap, QueryLayout wrapper
  layouts/QueryLayout.svelte # Global layout (TanStack Query, Echo)
  pages/{Auth,Chats,Welcome}.svelte
  components/
    ui/                     # shadcn-svelte components
    LoginForm, RegisterForm.svelte
  lib/echo.ts               # Pusher JS client for Reverb
  lib/utils.ts              # cn() helper (clsx + tailwind-merge)
  types/                    # Shared TS types + module augmentation
```

## Testing

- Backend: Pest PHP 4, SQLite in-memory (`DB_DATABASE=:memory:`).
- Feature tests extend `Tests\TestCase` (Laravel base).
- `tests/Feature/` and `tests/Unit/` suites.
- Run with `php artisan test` or `composer test`.
- No frontend test framework detected.

## CI (`.github/workflows/`)

- **lint.yml**: PHP 8.4, runs `composer lint` + `npm run format` + `npm run lint` (Pint, Prettier, ESLint).
- **tests.yml**: PHP 8.3/8.4/8.5, Node 22, copies `.env`, runs `php artisan key:generate`, `npm run build`, `composer types:check`, then `php artisan test`.

## ESLint conventions

- Type imports: `consistent-type-imports` with `separate-type-imports` fix style, `import/consistent-type-specifier-style: prefer-top-level`.
- Import order: `builtin > external > internal > parent > sibling > index`.
- Curly braces required on all control statements (`curly: error`).
- Padding lines around control structures (`if`, `return`, `for`, `while`, `do`, `switch`, `try`, `throw`).
- Brace style: 1tbs, no single-line.
- Ignored from lint: `vendor`, `node_modules`, `public`, `bootstrap/ssr`, `resources/js/{actions,routes,wayfinder}/**`, `resources/js/components/ui/*`.
